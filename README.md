# ElShimma ERP

## Overview

ElShimma ERP is a full-stack Enterprise Resource Planning (ERP) system designed to help businesses manage their daily operations through a modular architecture. The system aims to centralize inventory, warehouse, production, customer, supplier, and order management while providing secure authentication and scalable REST APIs.

The project is currently under active development.
